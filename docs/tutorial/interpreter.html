Interpreter Mode

FunLang runs as an interpreter by default, executing code immediately without compilation. This is the fastest way to develop and test FunLang programs.

Running Modes

Execute a File

Run a FunLang source file directly:

# Run a .fun file
funlang program.fun

# Example
echo 'let x = 10 in x * 2' > test.fun
funlang test.fun
# => 20

Evaluate an Expression

Use -e to evaluate a single expression:

# Evaluate expression directly
funlang -e "1 + 2 * 3"
# => 7

funlang -e "let square = fun x -> x * x in square 5"
# => 25

# Multi-line with shell
funlang -e "
let rec factorial = fun n ->
  if n <= 1 then 1
  else n * factorial (n - 1)
in factorial 10
"
# => 3628800

Interactive REPL

Use -i to start an interactive Read-Eval-Print Loop:

# Start REPL
funlang -i

# In REPL:
> let x = 10
val x : int = 10

> let y = 20
val y : int = 20

> x + y
val it : int = 30

> let double = fun x -> x * 2
val double : int -> int = <function>

> double 21
val it : int = 42
REPL Tips
  • Bindings persist across expressions
  • Use Ctrl+D or type exit to quit
  • Previous result is bound to it

Debug Options

Use these options to inspect how your code is processed:

--show-tokens

Display lexer output (tokenization):

funlang --show-tokens -e "1 + 2"

# Output:
Tokens:
  INT(1) PLUS INT(2) EOF

--show-ast

Display the Abstract Syntax Tree:

funlang --show-ast -e "let x = 1 in x + 2"

# Output:
AST:
  Let("x",
    Int(1),
    BinaryOp(Add,
      Var("x"),
      Int(2)))

--show-types

Display inferred types:

funlang --show-types -e "fun x -> x + 1"

# Output:
Types:
  (fun x -> x + 1) : int -> int

Combining Options

# Show everything
funlang --show-tokens --show-ast --show-types -e "1 + 2"

# Debug a file
funlang --show-ast --show-types program.fun

Output Options

--emit / -o

Format and emit the source code (pretty-print):

# Pretty-print to stdout
funlang --emit program.fun

# Save formatted output to file
funlang -o formatted.fun program.fun

--no-color

Disable colored output (useful for piping):

funlang --no-color program.fun > output.txt

Error Handling

--explain

Get detailed explanations for errors:

funlang --explain -e "1 + true"

# Output:
error[E101]: Type mismatch
  --> <expr>:1:5
  |
1 | 1 + true
  |     ^^^^
  = expected: int
  = found: bool

  Explanation:
  The + operator requires both operands to be integers.
  You provided an integer (1) and a boolean (true).

Logging

--log-level

Set verbosity level (debug, info, warn, error):

# Show debug information
funlang --log-level debug program.fun

# Only show errors
funlang --log-level error program.fun

--log-file

Write logs to a file:

funlang --log-file debug.log --log-level debug program.fun
