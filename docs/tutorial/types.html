Type System

FunLang is statically typed with automatic type inference. You rarely need to write type annotations - the compiler figures out types for you.

Type Inference

FunLang uses the Hindley-Milner type inference algorithm (Algorithm W) to automatically determine types:

Inferred Types

// int -> int
let double = fun x -> x * 2

// int -> bool
let isPositive = fun x -> x > 0

// string -> string -> string
let greet = fun name -> fun greeting -> greeting ^ ", " ^ name

// int list -> int
let rec sum = fun xs ->
  match xs with
  | [] -> 0
  | h :: t -> h + sum t

Polymorphic Types

Some functions work with any type. These have polymorphic types with type variables ('a, 'b, etc.):

// 'a -> 'a (identity function - works with any type)
let id = fun x -> x

// 'a * 'b -> 'b * 'a (swap tuple elements)
let swap = fun pair ->
  match pair with
  | (a, b) -> (b, a)

// 'a -> 'b -> 'a (returns first argument)
let first = fun x -> fun y -> x

// ('a -> 'b) -> 'a list -> 'b list
let rec map = fun f -> fun xs ->
  match xs with
  | [] -> []
  | h :: t -> f h :: map f t
Type Variables
'a, 'b, 'c are type variables (like generics). They represent "any type" and make functions polymorphic.

Viewing Inferred Types

Use the --show-types flag to see inferred types:

dotnet run --project src/FunLang -- --show-types myfile.fun

Algebraic Data Types

Define your own types using discriminated unions (sum types):

Basic Type Definition

type Color = Red | Green | Blue

Use the constructors to create values:

Using Color type
type Color = Red | Green | Blue

let toHex = fun c ->
  match c with
  | Red -> "#FF0000"
  | Green -> "#00FF00"
  | Blue -> "#0000FF"

toHex Green
=> "#00FF00"

Constructors with Data

Constructors can carry data using of:

Shape type
type Shape =
  | Circle of int
  | Rectangle of int * int

let area = fun shape ->
  match shape with
  | Circle r -> 3 * r * r     // approximation
  | Rectangle (w, h) -> w * h

area (Rectangle (4, 5))
=> 20

Polymorphic Types

Types can have type parameters for genericity:

Option type
type Option 'a = None | Some of 'a

let safeDivide = fun x -> fun y ->
  if y = 0 then None
  else Some (x / y)

let getOrElse = fun default -> fun opt ->
  match opt with
  | None -> default
  | Some x -> x

getOrElse -1 (safeDivide 10 0)
=> -1
Either type
type Either 'a 'b = Left of 'a | Right of 'b

let mapRight = fun f -> fun e ->
  match e with
  | Left x -> Left x
  | Right y -> Right (f y)

mapRight (fun x -> x * 2) (Right 21)
=> Right 42

Recursive Types

Types can reference themselves for recursive data structures:

Binary Tree
type Tree 'a =
  | Leaf of 'a
  | Node of Tree 'a * Tree 'a

let rec sumTree = fun tree ->
  match tree with
  | Leaf n -> n
  | Node (left, right) -> sumTree left + sumTree right

let myTree = Node (Leaf 1, Node (Leaf 2, Leaf 3))
sumTree myTree
=> 6
Custom List
type MyList 'a = Nil | Cons of 'a * MyList 'a

let rec myLength = fun xs ->
  match xs with
  | Nil -> 0
  | Cons (_, rest) -> 1 + myLength rest

let myList = Cons (1, Cons (2, Cons (3, Nil)))
myLength myList
=> 3

Multi-line Type Definitions

Use indentation for cleaner type definitions:

type Expr =
  | Num of int
  | Add of Expr * Expr
  | Mul of Expr * Expr
  | Neg of Expr
Tip
Algebraic data types are perfect for representing domain models, ASTs, state machines, and any data that can be one of several variants.

Type Error Messages

When types don't match, FunLang provides helpful error messages:

// Error: trying to add int and string
1 + "hello"
// Type error: expected int but got string

// Error: if branches have different types
if true then 1 else "two"
// Type error: branches have incompatible types int and string
