# Requirements: v14.0 Type Annotation Completeness

## Goal

Prelude 타입 어노테이션 작업 중 발견된 5가지 문제를 해결하여, 모든 Prelude 함수에 타입을 명시할 수 있게 한다.

## Requirements

### ANNOT-01: Array 타입 어노테이션 (Elaborate TEData→TArray 변환)

`'a array` 타입 어노테이션이 builtin의 `TArray` 타입과 unify 되어야 한다.

**현상:** `let create (n : int) (def : 'a) : 'a array = array_create n def` → `expected array<'b> but got 'a array` 타입 에러.

**원인:** `Elaborate.fs`에서 `TEData("array", [arg])` → `TData("array", [ty])` 로 변환되지만, builtin은 `TArray(ty)`를 반환. `TData` ≠ `TArray`.

**수락 기준:**
- `let f (arr : 'a array) : 'a = array_get arr 0` 이 타입 체크 통과
- `let g (n : int) (def : 'a) : 'a array = array_create n def` 가 타입 체크 통과
- Prelude/Array.fun 전체 함수에 타입 어노테이션 적용 후 723+ flt 테스트 통과

### ANNOT-02: 연산자 정의 타입 어노테이션 (OpName MixedParamList)

연산자 정의에서 파라미터 타입 어노테이션과 리턴 타입을 사용할 수 있어야 한다.

**현상:** `let (^^) (a : string) (b : string) : string = ...` → 파싱 에러.

**원인:** 파서에서 연산자 정의가 `OpName ParamList`만 지원하고, `OpName MixedParamList`를 지원하지 않음.

**수락 기준:**
- `let (op) (x : int) (y : int) : int = x + y` 가 파싱 및 타입 체크 통과
- `#[left 1] let (|>) (x : 'a) (f : 'a -> 'b) : 'b = f x` 가 파싱 통과 (AttributeList + OpName + MixedParamList)
- 리턴 타입 어노테이션도 지원: `let (op) (x : int) : int = ...`

### ANNOT-03: Instance 메서드 타입 어노테이션

typeclass instance 메서드 정의에서 파라미터 타입 어노테이션과 리턴 타입을 사용할 수 있어야 한다.

**현상:** `instance Show int = let show (x : int) : string = to_string x` → 파싱 에러.

**원인:** `InstanceMethod` 파서 규칙이 `ParamList`만 지원.

**수락 기준:**
- `instance Show int = let show (x : int) : string = to_string x` 가 파싱 통과
- `instance Eq int = let eq (x : int) (y : int) : bool = x = y` 가 파싱 통과
- 기존 어노테이션 없는 instance 정의도 하위 호환

### ANNOT-04: Mutable 컬렉션 타입 시스템 등록

HashSet, Queue, MutableList, StringBuilder 타입이 타입 시스템에 등록되어 어노테이션에 사용할 수 있어야 한다.

**현상:** 이 타입들의 함수에 타입 어노테이션을 쓸 수 없음.

**원인:** `Type.fs`에 `TArray`, `THashtable`만 있고, 나머지 4개 타입 없음.

**수락 기준:**
- `let add (hs : 'a hashset) (v : 'a) : unit = hashset_add hs v` 가 타입 체크 통과
- `let enqueue (q : 'a queue) (v : 'a) : unit = queue_enqueue q v` 가 타입 체크 통과
- `let add (ml : 'a mutablelist) (v : 'a) : unit = mutablelist_add ml v` 가 타입 체크 통과
- `let create () : stringbuilder = stringbuilder_create ()` 가 타입 체크 통과
- 해당 Prelude 파일들에 타입 어노테이션 적용 후 전체 테스트 통과

### ANNOT-05: 타입 변수 이름 안정화 (에러 메시지)

Prelude 변경이 사용자 코드의 타입 변수 이름에 영향을 주지 않아야 한다.

**현상:** Prelude에 타입 어노테이션 추가 후 `err-occurs-check.flt`의 타입 변수 이름이 `'k`/`'l` → `'q`/`'r`로 변경됨.

**원인:** 전역 `freshTypeVarIndex` 카운터가 Prelude 로딩 시 소비한 인덱스에 따라 사용자 코드 변수 이름이 밀림.

**수락 기준:**
- Prelude에 어노테이션을 추가/제거해도 사용자 코드의 에러 메시지 타입 변수 이름이 변하지 않음
- 타입 변수 카운터가 사용자 코드 처리 전에 리셋되거나, 스코프별로 독립 관리됨
