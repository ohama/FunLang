WASM Compilation

FunLang can compile programs to WebAssembly (WASM), allowing you to run FunLang code in browsers, serverless environments, or any WASM runtime like wasmtime.

Note
WASM compilation is currently MVP (Minimum Viable Product). It supports basic expressions but not all FunLang features yet.

Quick Start

Compile to WASM Binary

# Compile an expression to WASM
funlang --target wasm --output hello.wasm -e "1 + 2 * 3"

# Run with wasmtime
wasmtime --invoke main hello.wasm
# Output: 7

Compile to WAT Text Format

WAT (WebAssembly Text) is a human-readable format useful for debugging:

# Generate WAT text format
funlang --target wat --output hello.wat -e "1 + 2 * 3"

# View the generated WAT
cat hello.wat
Generated WAT
(module
  (func $main  (result i32)
    i32.const 1
    i32.const 2
    i32.const 3
    i32.mul
    i32.add
  )
  (export "main" (func $main))
)

CLI Options

OptionDescription
--target wasmCompile to WASM binary format (.wasm)
--target watCompile to WAT text format (.wat)
--output <path>Output file path (required for compilation)

Examples

Arithmetic Expressions

Compile and Run
# Basic arithmetic
funlang --target wasm --output calc.wasm -e "10 + 20 * 3"
wasmtime --invoke main calc.wasm
# => 70

# Division and modulo
funlang --target wasm --output div.wasm -e "17 / 5"
wasmtime --invoke main div.wasm
# => 3

funlang --target wasm --output mod.wasm -e "17 % 5"
wasmtime --invoke main mod.wasm
# => 2

Let Bindings

Local variables are compiled to WASM local variables:

Variable Binding
funlang --target wasm --output vars.wasm -e "let x = 10 in let y = 20 in x + y"
wasmtime --invoke main vars.wasm
# => 30
Generated WAT
(module
  (func $main  (result i32)
    (local $local_0 i32)
    (local $local_1 i32)
    i32.const 10
    local.set 0        ;; x = 10
    i32.const 20
    local.set 1        ;; y = 20
    local.get 0        ;; get x
    local.get 1        ;; get y
    i32.add            ;; x + y
  )
  (export "main" (func $main))
)

Conditional Expressions

If/then/else compiles to WASM if blocks:

Conditional
funlang --target wasm --output cond.wasm -e "if 5 > 3 then 100 else 200"
wasmtime --invoke main cond.wasm
# => 100

# Complex condition
funlang --target wasm --output max.wasm -e "let a = 15 in let b = 20 in if a > b then a else b"
wasmtime --invoke main max.wasm
# => 20

Comparison and Logical Operators

Comparisons
# Boolean result as int (1 = true, 0 = false)
funlang --target wasm --output cmp.wasm -e "10 > 5"
wasmtime --invoke main cmp.wasm
# => 1

funlang --target wasm --output eq.wasm -e "10 = 10"
wasmtime --invoke main eq.wasm
# => 1

# Logical operators
funlang --target wasm --output and.wasm -e "true and false"
wasmtime --invoke main and.wasm
# => 0

funlang --target wasm --output or.wasm -e "true or false"
wasmtime --invoke main or.wasm
# => 1

Compiling Files

You can also compile FunLang source files:

program.fun
let x = 10
let y = 20
let z = 30
x + y + z
funlang --target wasm --output program.wasm program.fun
wasmtime --invoke main program.wasm
# => 60

Module systemRequires multi-module WASM linking
Warning
If you try to compile unsupported features, you'll get a clear error message: 
funlang --target wasm --output test.wasm -e "fun x -> x + 1"

error[E303]: WASM compilation: unsupported feature 'lambda functions'
  --> :1:5
  |
1 | fun x -> x + 1
  |     ^
   = help: This feature requires closures or memory management

Running WASM

Using wasmtime

wasmtime is a fast, secure WASM runtime:

# Install wasmtime
curl https://wasmtime.dev/install.sh -sSf | bash

# Run compiled WASM
wasmtime --invoke main program.wasm

Using wasmer

wasmer is another popular WASM runtime:

# Install wasmer
curl https://get.wasmer.io -sSfL | sh

# Run compiled WASM
wasmer run program.wasm --invoke main

In the Browser

You can load and run the compiled WASM in a browser:

run.html
<script>
async function runWasm() {
    const response = await fetch('program.wasm');
    const bytes = await response.arrayBuffer();
    const { instance } = await WebAssembly.instantiate(bytes);

    const result = instance.exports.main();
    console.log('Result:', result);
}
runWasm();
</script>

In Node.js

// run.js
const fs = require('fs');
const wasmBuffer = fs.readFileSync('program.wasm');

WebAssembly.instantiate(wasmBuffer).then(result => {
    const main = result.instance.exports.main;
    console.log('Result:', main());
});

How It Works

Compilation Pipeline

FunLang Source  →  Parse (AST)  →  Type Check  →  WASM IR  →  Binary
     ↓                  ↓               ↓             ↓           ↓
 "1 + 2"         EBinaryOp(...)      int          [I32Const,   0x00 0x61
                                                   I32Add]     0x73 0x6d...

WASM Basics

WASM is a stack-based virtual machine. FunLang expressions compile to stack operations:

FunLangWASM Instructions
42i32.const 42
truei32.const 1
falsei32.const 0
a + b[a]; [b]; i32.add
a - b[a]; [b]; i32.sub
a * b[a]; [b]; i32.mul
a / b[a]; [b]; i32.div_s
a < b[a]; [b]; i32.lt_s
not a[a]; i32.eqz
-ai32.const 0; [a]; i32.sub
let x = e in body[e]; local.set x; [body]
x (variable)local.get x
if c then t else e[c]; if (result i32) [t] else [e] end

Future Plans

The WASM backend will be extended in future versions:

  • Phase 2: Function definitions (non-recursive)
  • Phase 3: Recursive functions (function table)
  • Phase 4: Linear memory for tuples/lists
  • Phase 5: Closures (runtime support)
  • Phase 6: Garbage collection
