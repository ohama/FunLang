# Milestone v12.0: Infix Operator Reform

**Status:** SHIPPED 2026-04-03
**Phases:** 84-87
**Total Plans:** 4

## Overview

Reform FunLang's hardcoded infix operator handling by introducing a #[left N] / #[right N] attribute system and a Pratt post-processor. The three special-cased operators (|>, >>, <<) become ordinary Prelude definitions, their dedicated AST nodes and tokens are removed.

## Key Decisions
- #[ lexes as single ATTR_OPEN token (zero conflicts)
- FixityEnv precedence: INFIXOP0=4, INFIXOP1=5, INFIXOP2=6, INFIXOP3=7, INFIXOP4=8
- |> at #[left 1], >> at #[right 2], << at #[left 2]
- Pratt post-processor: flatten same-LALR-level chains, rebuild with precedence climbing
- applyFunc closure bug fixed: self-name injection guard for compose chains
