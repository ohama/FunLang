  <action>
**Cli.fs:** Add `Emit_Typed_Ast` case to the `CliArgs` DU, placed after `Emit_Type` (before `Check`). Add the corresponding Usage match arm: `| Emit_Typed_Ast -> "emit typed AST as JSON (span->type map + top-level bindings)"`.

**Program.fs:** Add three things:

1. At the top of Program.fs, add `open System.Text.Json.Nodes` (no new NuGet packages needed, built into .NET 10).

2. Add a private `serializeTypedModule` function before the `main` function. It takes `(userFile: string)` and `(tm: ExportApi.TypedModule)` and returns a JSON string. Implementation:
   - Create a `JsonObject` root with two keys: `"annotations"` (JsonArray) and `"bindings"` (JsonObject).
   - For annotations: iterate `tm.AnnotationMap`, filter entries where `kv.Key.FileName = System.IO.Path.GetFullPath(userFile)` (user file spans only, excludes prelude). For each matching entry, create a JsonObject with `"span"` (JsonObject with `"startLine"`, `"startCol"`, `"endLine"`, `"endCol"` as ints) and `"type"` (string from `Type.formatTypeNormalized kv.Value`). Add to the array.
   - For bindings: iterate `tm.BindingEnv`, filter entries where `not (Map.containsKey kv.Key tm.BuiltinSchemes)` (excludes builtins). For each, add `kv.Key -> Type.formatSchemeNormalized kv.Value` to the bindings JsonObject.
   - Return `root.ToJsonString()`.

3. Add handler branch in the `elif` chain in the `main` function. Place it BEFORE the generic `elif results.Contains File then` catch-all (currently at line ~422) and after the existing `--expr only` block (line ~404). The exact placement should be right before the comment `// file only -- use module pipeline with IndentFilter`. Follow the existing Emit_Type+File pattern:
   ```
   elif results.Contains Emit_Typed_Ast && results.Contains File then
       let filename = results.GetResult File
       if File.Exists filename then
           try
               let typed = ExportApi.typeCheckFile filename
               let json = serializeTypedModule filename typed
               printfn "%s" json
               0
           with ex ->
               eprintfn "Error: %s" ex.Message
               1
       else
           eprintfn "File not found: %s" filename
           1
   ```

**IMPORTANT placement notes:**
- The branch MUST come before the generic `elif results.Contains File then` catch-all, otherwise it will never be reached.
- Use `Emit_Typed_Ast` (underscores) to match the Argu convention used by all existing cases.
