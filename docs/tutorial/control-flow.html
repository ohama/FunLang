Control Flow

FunLang provides two primary control flow mechanisms: conditionals (if-then-else) and pattern matching (match).

Conditionals

The if-then-else expression evaluates a condition and returns one of two values:

Basic if expression
if true then 1 else 2
=> 1
Absolute value
let abs = fun x ->
  if x < 0 then -x
  else x

abs (-42)
=> 42
Note
In FunLang, if is an expression that returns a value. Both branches must have the same type.

Nested Conditionals

Nested if
let sign = fun x ->
  if x > 0 then "positive"
  else if x < 0 then "negative"
  else "zero"

sign (-5)
=> "negative"

Multi-line If

Use indentation for multi-line branches:

Multi-line branches
let describe = fun n ->
  if n > 100 then
    let x = n / 100
    x * 100
  else
    n

describe 250
=> 200

Pattern Matching

Pattern matching is a powerful way to destructure data and make decisions based on structure:

Basic match
let describe = fun n ->
  match n with
  | 0 -> "zero"
  | 1 -> "one"
  | 2 -> "two"
  | _ -> "many"

describe 1
=> "one"

Pattern Types

Literal Patterns

Match exact values:

match x with
| 0 -> "zero"           // integer literal
| true -> "yes"         // boolean literal
| "hello" -> "hi"      // string literal

Variable Patterns

Bind the matched value to a name:

match x with
| n -> n + 1          // n binds to whatever x is

Wildcard Pattern

Match anything without binding:

match x with
| 0 -> "zero"
| _ -> "not zero"     // _ matches anything

Tuple Patterns

Tuple pattern
let add = fun pair ->
  match pair with
  | (x, y) -> x + y

add (3, 4)
=> 7

List Patterns

List patterns
let describe = fun xs ->
  match xs with
  | [] -> "empty"
  | [x] -> "one element"
  | [x; y] -> "two elements"
  | h :: t -> "head and tail"

describe [1; 2; 3]
=> "head and tail"

Constructor Patterns

Match user-defined type constructors:

Constructor pattern
type Option 'a = None | Some of 'a

let getOrElse = fun default -> fun opt ->
  match opt with
  | None -> default
  | Some x -> x

getOrElse 0 (Some 42)
=> 42

Pattern Matching on Recursive Structures

Sum of list
let rec sum = fun xs ->
  match xs with
  | [] -> 0
  | h :: t -> h + sum t

sum [1; 2; 3; 4; 5]
=> 15

Guards

Add conditions to patterns with when:

Pattern with guard
let classify = fun n ->
  match n with
  | x when x < 0 -> "negative"
  | x when x = 0 -> "zero"
  | x when x < 10 -> "small"
  | _ -> "large"

classify 5
=> "small"
Guards with list patterns
let rec takeWhilePositive = fun xs ->
  match xs with
  | [] -> []
  | h :: t when h > 0 -> h :: takeWhilePositive t
  | _ -> []

takeWhilePositive [3; 2; 1; 0; -1; 5]
=> [3; 2; 1]

Exhaustiveness Checking

FunLang checks that pattern matches cover all cases and warns about redundant patterns:

Non-exhaustive pattern warning
type Option 'a = None | Some of 'a

let getValue = fun opt ->
  match opt with
  | Some x -> x
  // Warning: Non-exhaustive pattern match
  // Missing case(s): None
Redundant pattern warning
let test = fun x ->
  match x with
  | true -> 1
  | false -> 2
  | true -> 3   // Warning: Pattern is redundant (never matches)

Writing Exhaustive Patterns

Best Practice

Always handle all cases or use a wildcard (_) as a catch-all:

// Option 1: Handle all cases explicitly
let getValue = fun opt ->
  match opt with
  | Some x -> x
  | None -> 0

// Option 2: Use wildcard as fallback
let head = fun xs ->
  match xs with
  | h :: _ -> h
  | _ -> 0

// For bools: use true and false explicitly
let describe = fun b ->
  match b with
  | true -> "yes"
  | false -> "no"
