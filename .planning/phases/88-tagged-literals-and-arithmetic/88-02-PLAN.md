### E. Fix arithmetic: Mul/Div/Rem untag-retag (ARITH-02)

**Multiply** (~line 26-30): Untag both operands, multiply, retag:
```fsharp
| Multiply (lhs, rhs, _) ->
    let (lv, lops) = elaborateExpr env lhs
    let (rv, rops) = elaborateExpr env rhs
    let (la, untagLOps) = emitUntag env lv
    let (rb, untagROps) = emitUntag env rv
    let raw = { Name = freshName env; Type = I64 }

```
