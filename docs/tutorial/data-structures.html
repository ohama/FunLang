Data Structures

FunLang provides two built-in compound data structures: tuples and lists.

Tuples

Tuples group multiple values of potentially different types into a single value.

Creating Tuples

// Pair (2-tuple)
(1, 2)

// Triple (3-tuple)
("hello", 42, true)

// Nested tuples
((1, 2), (3, 4))

// Mixed types
("name", 25, [1; 2; 3])

Tuple Types

Tuple types are written with * between element types:

  • (1, 2) has type int * int
  • ("hello", true) has type string * bool
  • (1, "a", true) has type int * string * bool

Destructuring Tuples

Use pattern matching to extract tuple elements:

Tuple destructuring
let pair = (10, 20)

match pair with
| (x, y) -> x + y
=> 30
Swap function
let swap = fun pair ->
  match pair with
  | (a, b) -> (b, a)

swap (1, 2)
=> (2, 1)

Tuple in Let Binding

Pattern in let
let point = (3, 4)

match point with
| (x, y) ->
    let squared = x * x + y * y
    squared
=> 25

Lists

Lists are homogeneous sequences - all elements must have the same type.

Creating Lists

// Empty list
[]

// List of integers
[1; 2; 3]

// List of strings
["a"; "b"; "c"]

// List of booleans
[true; false; true]

// Nested lists
[[1; 2]; [3; 4]; [5; 6]]

The Cons Operator (::)

The :: operator prepends an element to a list:

Cons operator
// Prepend to list
1 :: [2; 3]
=> [1; 2; 3]
Building lists with cons
// Build list from empty
1 :: 2 :: 3 :: []
=> [1; 2; 3]
Note
The cons operator :: is right-associative, so 1 :: 2 :: 3 :: [] is parsed as 1 :: (2 :: (3 :: [])).

List Types

List types are written as element_type list:

  • [1; 2; 3] has type int list
  • ["a"; "b"] has type string list
  • [[1]; [2]] has type int list list
  • [] has type 'a list (polymorphic empty list)

Pattern Matching on Lists

Lists have two patterns: empty list [] and cons head :: tail.

List head
let head = fun xs ->
  match xs with
  | [] -> 0        // default for empty
  | h :: _ -> h    // h is head, _ ignores tail

head [5; 4; 3]
=> 5
List length
let rec length = fun xs ->
  match xs with
  | [] -> 0
  | _ :: t -> 1 + length t

length [1; 2; 3; 4; 5]
=> 5
Sum of list
let rec sum = fun xs ->
  match xs with
  | [] -> 0
  | h :: t -> h + sum t

sum [1; 2; 3; 4; 5]
=> 15

More List Patterns

Matching specific structures
let describe = fun xs ->
  match xs with
  | [] -> "empty"
  | [x] -> "singleton"
  | [x; y] -> "pair"
  | _ -> "many"

describe [1; 2]
=> "pair"
Tip
Always handle the empty list case [] when writing recursive list functions to avoid infinite recursion.

Combining Tuples and Lists

List of tuples
let points = [(1, 2); (3, 4); (5, 6)]

let rec sumX = fun pts ->
  match pts with
  | [] -> 0
  | (x, _) :: rest -> x + sumX rest

sumX points
=> 9
