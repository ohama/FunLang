Fix the LambdaAnnot span collision bug (Issue #18) by assigning each parameter its own span in the parser grammar rules and desugaring functions.

Purpose: Nested LambdaAnnot nodes currently share one span, causing annotationMap to overwrite inner parameter types with the outermost arrow type. Each LambdaAnnot must get a unique span derived from its parameter's source position.

Output: Modified Parser.fsy with per-parameter spans flowing through AnnotParam, MixedParam, desugarAnnotParams, and desugarMixedParams, plus all 33+ callsites updated.
</objective>

  <files>src/FunLang/Parser.fsy</files>
  <action>
Modify Parser.fsy header functions and grammar rules to pass per-parameter spans instead of a shared outer span:

1. **`desugarAnnotParams` signature change:**
   - From: `(paramList: (string * TypeExpr) list) (body: Expr) (span: Span) : Expr`
   - To: `(paramList: (string * TypeExpr * Span) list) (body: Expr) : Expr`
   - Each match arm uses the span from the tuple:
     ```
     | [(name, ty, sp)] -> LambdaAnnot(name, ty, body, sp)
     | (name, ty, sp) :: rest -> LambdaAnnot(name, ty, desugarAnnotParams rest body, sp)
     ```

2. **`AnnotParam` rule change:**
   - From: `{ ($2, $4) }`
   - To: `{ ($2, $4, ruleSpan parseState 1 5) }`
   - This captures the span of each `(name : Type)` individually.

3. **`desugarAnnotParams` callsites (2 rules, lines ~244, ~246):**
   - Remove the trailing `(ruleSpan parseState ...)` argument.
   - From: `desugarAnnotParams $2 $4 (ruleSpan parseState 1 4)`
   - To: `desugarAnnotParams $2 $4`

4. **`desugarMixedParams` signature change:**
   - From: `(paramList: Choice<string, string * TypeExpr> list) (body: Expr) (span: Span) : Expr`
   - To: `(paramList: Choice<string * Span, string * TypeExpr * Span> list) (body: Expr) : Expr`
   - Each match arm uses the span from the tuple:
     ```
     | Choice1Of2 (name, sp) :: rest -> Lambda(name, desugarMixedParams rest body, sp)
     | Choice2Of2 (name, ty, sp) :: rest -> LambdaAnnot(name, ty, desugarMixedParams rest body, sp)
     ```

5. **`MixedParam` rule changes:**
   - Plain param: From `{ Choice1Of2 $1 }` To `{ Choice1Of2 ($1, symSpan parseState 1) }`
   - Annotated param: From `{ Choice2Of2 ($2, $4) }` To `{ Choice2Of2 ($2, $4, ruleSpan parseState 1 5) }`

6. **All ~33 `desugarMixedParams` callsites:** Remove the trailing span argument from every callsite. Each callsite currently passes a `span` or `(ruleSpan parseState ...)` as the third argument -- remove it.

7. **LetRec first-param separation pattern:** After `desugarMixedParams` returns, the match extracts the first Lambda/LambdaAnnot. The match patterns `Lambda(p, b, _)` and `LambdaAnnot(p, ty, b, _)` remain unchanged since they already ignore the span with `_`.

IMPORTANT: Do NOT modify `desugarMultiParamLambda` -- it handles unannotated lambdas and is out of scope per research.
