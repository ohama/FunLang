  <action>
Create `src/FunLang/ExportApi.fs` with:

1. Module declaration: `module ExportApi`

2. Opens: `System.IO`, `FSharp.Text.Lexing`, `Ast`, `TypeCheck`, `Diagnostic`, `FunLang.IndentFilter`

3. TypedModule record type with three fields:
   - `AnnotationMap: Map<Ast.Span, Type.Type>` — immutable snapshot of per-expression types
   - `BindingEnv: TypeCheck.BindingEnv` — full binding environment (builtins + prelude + user)
   - `BuiltinSchemes: Type.TypeEnv` — builtin-only schemes for consumer filtering

4. Private `parseModuleFromString` helper — duplicate from Program.fs (established pattern; the function is also duplicated in Prelude.fs). This must be the position-tracking version that uses IndentFilter, not a simplified version — correct spans are critical for the annotation map. Copy the implementation from Program.fs exactly: create LexBuffer, collect tokens with positions, filter through IndentFilter, create second LexBuffer for parser, feed filtered tokens via mutable index.

5. Public `typeCheckFile (filePath: string) : TypedModule` function:
   - `Path.GetFullPath(filePath)` for absolute path
   - `File.ReadAllText(absPath)` to read source
   - `Prelude.loadPrelude None None` to get prelude environments
   - Set `TypeCheck.currentTypeCheckingFile <- absPath` (required for relative import resolution)
   - Call `parseModuleFromString input absPath`
   - Call `TypeCheck.typeCheckModuleWithPrelude` with all 6 prelude env fields + parsed module
   - On `Error diags`: `failwith` with formatted diagnostics (matches codebase error style)
   - On `Ok (_warnings, _ctorEnv, _recEnv, _classEnv, _instEnv, _modules, typeEnv)`:
     - CRITICAL: Snapshot `Bidir.annotationMap` IMMEDIATELY — `Seq.map (fun kv -> (kv.Key, kv.Value)) |> Map.ofSeq`
     - Return `{ AnnotationMap = snapshot; BindingEnv = TypeCheck.exportBindingEnv typeEnv; BuiltinSchemes = TypeCheck.initialTypeEnv }`

In `FunLang.fsproj`, insert `<Compile Include="ExportApi.fs" />` with a comment AFTER the Prelude.fs entry (line 117) and BEFORE the Repl.fs entry (line 119). Add comment: `<!-- 13.5. Export API (uses TypeCheck + Prelude) -->`.

Do NOT place ExportApi.fs after Repl/ProjectFile/Cli — it must come right after Prelude.fs for clarity and to ensure Prelude module is visible.
