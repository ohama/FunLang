Language Basics

This section covers the fundamental building blocks of FunLang: literals, operators, variables, and comments.

Literals

FunLang supports several primitive types:

Integers

42          // positive integer
-17         // negative integer
0           // zero

Booleans

true        // boolean true
false       // boolean false

Strings

"Hello"     // string literal
"Hello, World!"
""          // empty string

Unit

()          // unit value (like void)

Operator Precedence

From highest to lowest:

  1. Function application (left to right)
  2. not (unary)
  3. *, /, %
  4. +, -, ^
  5. :: (cons, right associative)
  6. =, <>, <, >, <=, >=
  7. &&
  8. ||

Variables

Variables are bound using let. All bindings are immutable.

Variable binding
let x = 42
let name = "FunLang"
let isAwesome = true

x + 8
=> 50

Nested Let Bindings

You can nest let bindings using indentation:

Nested bindings
let result =
  let x = 10
  let y = 20
  x + y

result
=> 30
Note
FunLang uses indentation-based syntax. The body of a let binding must be indented relative to the let keyword.

Shadowing

You can rebind a variable name, which shadows the previous binding:

Variable shadowing
let x = 10
let x = x + 5  // shadows previous x
x
=> 15

Comments

Single-line comments start with //:

// This is a comment
let x = 42  // inline comment

// Multi-line comments
// use multiple // lines
// like this
let y = 10
Tip
Comments are preserved when using the --emit formatter option.
