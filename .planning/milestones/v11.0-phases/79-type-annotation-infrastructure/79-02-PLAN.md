<task type="auto">
  <name>Task 1: Add annotation recording to every synth return point</name>
  <files>src/FunLang/Bidir.fs</files>
  <action>
For every match arm in the `synth` function that returns `(Subst * Type)`, add annotation recording before the return. The pattern depends on the arm:

**For literal/simple arms** (Number, Bool, Str, CharExpr, Unit, etc.):
The type is already known. Record directly:
```fsharp
| Number (_, span) ->
    annotationMap.[span] <- TInt
    (empty, TInt)
```

**For recursive/compound arms** (App, Let, If, Lambda, Match, BinOp, etc.):
Apply the final composed substitution to the result type before recording:
```fsharp
let finalTy = apply finalSubst resultTy
annotationMap.[spanOf expr] <- finalTy
(finalSubst, finalTy)
```

**Key rules:**
1. Always record `apply finalSubst ty`, never raw `ty` — types must be fully resolved
2. Use `spanOf expr` or the span already destructured from the pattern
3. For arms that delegate to helper functions (e.g., synthLet, synthMatch), record at the point where the final (Subst, Type) is returned back in synth — OR inside the helper if it has a clear return point
4. For GADT Match in synth: both the GADT branch and the non-GADT branch must record the outer Match node's type
5. Skip recording for `unknownSpan` — the `TypeAnnotationMap.record` helper already handles this, but since we're writing directly to `annotationMap.[span]`, use a guard: `if span <> Ast.unknownSpan then annotationMap.[span] <- ...` OR use `TypeAnnotationMap.record annotationMap span ty` instead of direct dictionary access

**Approach:** Use `TypeAnnotationMap.record annotationMap (spanOf expr) finalTy` for consistency and to get the unknownSpan filtering for free. Add `open TypeAnnotationMap` is NOT needed — just call the fully qualified function, or since Bidir.fs already defines annotationMap at module scope, access the helper directly.

Actually, the simplest approach: define a local helper at the top of `synth`:
```fsharp
let recordTy span ty = if span <> Ast.unknownSpan then annotationMap.[span] <- ty
```
Then use `recordTy span finalTy` at every return point. This is the least invasive change.

**For the `check` function:** The subsumption fallback already calls synth, so most cases are covered. BUT: the GADT Match arm in check mode must explicitly record the outer Match node type. Find the GADT match handling in `check` and add recording there.

**Completeness:** Cross-reference every arm in `synth`'s match against the arms in `Ast.spanOf`. Every Expr variant that appears in `spanOf` must have a corresponding recording in synth. List each variant as you go to confirm coverage.
