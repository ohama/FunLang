FunLang Tutorial

Welcome to the FunLang tutorial! FunLang is a statically-typed functional programming language with Hindley-Milner type inference, designed for learning functional programming concepts.

Features

  • First-class functions - Functions are values that can be passed around
  • Pattern matching - Powerful destructuring of data
  • Algebraic data types - Define your own types with discriminated unions
  • Static type inference - Types are inferred automatically (Hindley-Milner)
  • Indentation-based syntax - Clean, Python-like syntax without braces
  • Module system - Organize code into reusable modules

Installation

Requirements

.NET 9.0 or later is required to build and run FunLang.

Build from Source

# Clone the repository
git clone https://github.com/your-repo/FunLang.git
cd FunLang

# Build
dotnet build

# Run a FunLang file
dotnet run --project src/FunLang -- myprogram.fun

Hello World

Let's start with the simplest FunLang program:

hello.fun
"Hello, FunLang!"
=> "Hello, FunLang!"

Running FunLang

# Run a file
dotnet run --project src/FunLang -- hello.fun

# Evaluate an expression directly
dotnet run --project src/FunLang -- -e "1 + 2 * 3"

# Start interactive REPL
dotnet run --project src/FunLang -- -i

Quick Example

Here's a taste of what FunLang looks like:

Factorial function
let rec factorial = fun n ->
  if n <= 1 then 1
  else n * factorial (n - 1)

factorial 5
=> 120
Tip
FunLang uses indentation-based syntax like Python. No braces or semicolons needed!
