# Roadmap: v14.0 Type Annotation Completeness

## Overview

Prelude 타입 어노테이션 작업 중 발견된 5가지 타입 시스템/파서 갭을 해결한다. 모든 Prelude 함수에 타입을 명시할 수 있는 상태를 목표로 한다.

**Phases:** 5 (91-95)
**Requirements:** 5
**Start:** Phase 91

---

## Phase 91: Array 타입 어노테이션 (Elaborate TEData→TArray)

**Goal:** `'a array` 타입 어노테이션이 builtin `TArray` 타입과 정상 unify 되어 Array.fun에 타입 명시 가능.

**Dependencies:** None (독립)

**Requirements:** ANNOT-01

**Tasks:**
1. `Elaborate.fs`의 `TEData` 처리에서 `"array"` 이름을 `TArray`로 변환하는 특수 케이스 추가
2. `substTypeExprWithMap`에도 동일 처리 추가
3. Prelude/Array.fun에 타입 어노테이션 적용
4. 기존 flt 테스트 전체 통과 확인

**Success Criteria:**
1. `let f (arr : 'a array) : 'a = array_get arr 0` 타입 체크 통과
2. Prelude/Array.fun 전체 함수 타입 어노테이션 후 723+ flt 통과

---

## Phase 92: 연산자 정의 타입 어노테이션

**Goal:** `let (op) (x : T) (y : U) : R = ...` 문법 지원으로 연산자에도 타입 명시 가능.

**Dependencies:** None (독립)

**Requirements:** ANNOT-02

**Tasks:**
1. `Parser.fsy`에 `LET OpName MixedParamList EQUALS SeqExpr` 규칙 추가 (+ INDENT/DEDENT 변형)
2. `LET OpName MixedParamList COLON TypeExpr EQUALS SeqExpr` 리턴 타입 규칙 추가
3. `AttributeList LET OpName MixedParamList ...` 규칙 추가 (fixity attribute 호환)
4. Prelude/Core.fun 연산자들에 타입 어노테이션 적용
5. flt 테스트 추가 및 전체 통과 확인

**Success Criteria:**
1. `let (^^) (a : string) (b : string) : string = string_concat a b` 파싱/타입 체크 통과
2. `#[left 1] let (|>) (x : 'a) (f : 'a -> 'b) : 'b = f x` 파싱 통과

---

## Phase 93: Instance 메서드 타입 어노테이션

**Goal:** typeclass instance 메서드에서 파라미터/리턴 타입 어노테이션 사용 가능.

**Dependencies:** None (독립)

**Requirements:** ANNOT-03

**Tasks:**
1. `Parser.fsy`의 `InstanceMethod` 규칙에 `MixedParamList` 변형 추가
2. 리턴 타입 어노테이션 (`COLON TypeExpr`) 변형 추가
3. `desugarMixedParams` 활용하여 기존 `InstanceDecl` AST와 호환
4. Prelude/Typeclass.fun에 타입 어노테이션 적용
5. flt 테스트 추가 및 전체 통과 확인

**Success Criteria:**
1. `instance Show int = let show (x : int) : string = to_string x` 파싱/실행 통과
2. `instance Eq int = let eq (x : int) (y : int) : bool = x = y` 파싱/실행 통과

---

## Phase 94: Mutable 컬렉션 타입 등록

**Goal:** HashSet, Queue, MutableList, StringBuilder가 타입 시스템에 등록되어 어노테이션 가능.

**Dependencies:** Phase 91 (Array 패턴 참고)

**Requirements:** ANNOT-04

**Tasks:**
1. `Type.fs`에 `THashSet of Type`, `TQueue of Type`, `TMutableList of Type`, `TStringBuilder` 추가
2. `Elaborate.fs`에서 해당 타입 이름 → 내부 타입 변환 추가
3. `Unify.fs`, `Bidir.fs`, `Infer.fs` 등에서 새 타입 처리 추가
4. `Format.fs`/`Type.fs`의 formatType에 새 타입 포맷 추가
5. 관련 builtin 함수들의 타입 시그니처 등록
6. Prelude 파일들에 타입 어노테이션 적용
7. flt 테스트 전체 통과 확인

**Success Criteria:**
1. 4개 Prelude 모듈(HashSet, Queue, MutableList, StringBuilder) 전체 함수에 타입 어노테이션 적용
2. 전체 flt 테스트 통과

---

## Phase 95: 타입 변수 이름 안정화

**Goal:** Prelude 변경이 사용자 코드의 에러 메시지 타입 변수 이름에 영향을 주지 않음.

**Dependencies:** None (독립, 마지막에 수행)

**Requirements:** ANNOT-05

**Tasks:**
1. `freshTypeVarIndex` 카운터 현황 분석 (전역 vs 스코프)
2. 사용자 코드 타입 추론 시작 전 카운터 리셋 메커니즘 구현 (또는 스코프별 카운터)
3. Prelude 어노테이션 추가/제거 시 에러 메시지 안정성 검증
4. 영향받는 flt 테스트의 기대값이 Prelude 변경에 무관하게 유지되는지 확인

**Success Criteria:**
1. Prelude에 어노테이션 추가/제거 후에도 `err-occurs-check.flt` 등 에러 테스트의 타입 변수 이름 불변
2. 전체 flt 테스트 통과
