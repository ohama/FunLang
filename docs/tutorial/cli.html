CLI Reference

Complete reference for FunLang command-line options.

Basic Usage

funlang [OPTIONS] [FILE]
funlang -e <expression>
funlang -i

Input Modes

File Input

# Run a FunLang source file
funlang myprogram.fun
funlang path/to/script.fun

Expression Mode (-e)

# Evaluate an expression directly
funlang -e "1 + 2 * 3"
funlang -e "let x = 10 in x * 2"
funlang -e "[1; 2; 3]"
Tip
Use quotes around expressions with spaces or special characters.

Interactive REPL (-i)

# Start interactive mode
funlang -i

# REPL session example
> let x = 42
val x : int = 42
> x * 2
val it : int = 84
> :quit

Debug Options

--show-tokens

Display the token stream from the lexer:

Command
funlang --show-tokens -e "1 + 2"
Output
Tokens:
  INT 1 at (1, 1)
  PLUS at (1, 3)
  INT 2 at (1, 5)
  EOF at (1, 6)

3

--show-ast

Display the parsed Abstract Syntax Tree:

Command
funlang --show-ast -e "let x = 1 in x + 2"
Output
AST:
ELet(
  name = "x",
  value = ELiteral(LInt 1),
  body = EBinaryOp(
    op = Add,
    left = EVariable "x",
    right = ELiteral(LInt 2)
  )
)

3

--show-types

Display inferred types for all bindings:

Command
funlang --show-types -e "let double = fun x -> x * 2 in double 21"
Output
Types:
  double : int -> int
  result : int

42

--show-indents

Display INDENT/DEDENT tokens inserted by the indentation processor:

Command
funlang --show-indents myfile.fun

--debug (-d)

Enable all debug output (equivalent to combining all --show-* options):

funlang -d myprogram.fun

--trace

Trace specific compilation phases (comma-separated):

# Trace lexer phase only
funlang --trace lexer myprogram.fun

# Trace parser and type checker
funlang --trace parser,typecheck myprogram.fun

# Available phases: lexer, parser, typecheck, eval
funlang --trace lexer,parser,typecheck,eval myprogram.fun

Output Options

--emit (-o)

Format and output source code. Comments are preserved.

# Output to stdout
funlang --emit myprogram.fun

# Output to file
funlang --emit formatted.fun myprogram.fun
funlang -o formatted.fun myprogram.fun
Input (messy.fun)
// Calculate sum
let   x=1
let y =   2
x+y   // result
Output (--emit)
// Calculate sum
let x = 1
let y = 2
x + y  // result

--no-color

Disable ANSI color codes in output (useful for piping to files):

funlang --no-color myprogram.fun > output.txt

Error Explanation

--explain

Show detailed explanation for error codes:

# Explain a specific error code
funlang --explain E202

# List all error codes
funlang --explain all

Logging Options

--log-level

Set the logging verbosity level:

# Available levels: debug, info, warning, error, fatal
funlang --log-level debug myprogram.fun
funlang --log-level warning myprogram.fun

--log-file

Write logs to a file:

funlang --log-file debug.log --log-level debug myprogram.fun

Examples

Quick Evaluation

# Simple arithmetic
funlang -e "2 + 2"
# => 4

# Function definition and call
funlang -e "let square = fun x -> x * x in square 5"
# => 25

# List operations
funlang -e "[1; 2; 3]"
# => [1; 2; 3]

Debugging a Program

# See what tokens are generated
funlang --show-tokens myprogram.fun

# Check the parsed AST
funlang --show-ast myprogram.fun

# Verify type inference
funlang --show-types myprogram.fun

# Full debug mode
funlang -d myprogram.fun

Formatting Code

# Format and display
funlang --emit messy.fun

# Format and save
funlang --emit clean.fun messy.fun

# Format in place (using shell)
funlang --emit > temp.fun messy.fun && mv temp.fun messy.fun

Production Usage

# Run without colors (for CI/CD)
funlang --no-color program.fun

# Log errors to file
funlang --log-file errors.log --log-level error program.fun

WASM Compilation

FunLang can compile programs to WebAssembly for portable execution.

--target

Set the compilation target:

# Compile to WASM binary
funlang --target wasm --output program.wasm -e "1 + 2 * 3"

# Compile to WAT text format (for debugging)
funlang --target wat --output program.wat -e "1 + 2 * 3"

# Default: interpret (no compilation)
funlang -e "1 + 2 * 3"

--output

Specify output file path (required for WASM compilation):

# Compile expression
funlang --target wasm --output hello.wasm -e "let x = 10 in x * 2"

# Compile file
funlang --target wasm --output program.wasm myprogram.fun

Running WASM Output

# Using wasmtime
wasmtime --invoke main program.wasm

# Using wasmer
wasmer run program.wasm --invoke main
Tip
See the WASM Compilation tutorial for detailed examples and supported features.
