Functions

Functions are first-class values in FunLang. They can be assigned to variables, passed as arguments, and returned from other functions.

Lambda Expressions

Functions are created using the fun keyword:

Basic lambda
fun x -> x + 1
=> <function>

Naming Functions

Bind a function to a name with let:

Named function
let double = fun x -> x * 2

double 21
=> 42
More examples
let square = fun x -> x * x
let negate = fun x -> -x
let isPositive = fun x -> x > 0

(square 5, negate 3, isPositive 10)
=> (25, -3, true)

Function Types

Function types are written as input -> output:

  • fun x -> x + 1 has type int -> int
  • fun x -> x > 0 has type int -> bool
  • fun x -> x has type 'a -> 'a (polymorphic identity)

Currying

Multi-parameter functions are represented as nested functions (currying):

Curried function
// A function that takes x, then returns a function that takes y
let add = fun x -> fun y -> x + y

// Full application
add 3 4
=> 7
Note
add 3 4 is parsed as (add 3) 4. First add 3 returns a function, then that function is applied to 4.

Partial Application

Apply some but not all arguments to create a specialized function:

Partial application
let add = fun x -> fun y -> x + y

// Partial application: add5 is a function waiting for one more argument
let add5 = add 5

add5 10
=> 15
Multiple partial applications
let multiply = fun x -> fun y -> x * y

let double = multiply 2
let triple = multiply 3

(double 5, triple 5)
=> (10, 15)

Three or More Parameters

Three parameters
let addThree = fun x -> fun y -> fun z -> x + y + z

addThree 1 2 3
=> 6

Higher-Order Functions

Functions that take functions as arguments or return functions are called higher-order functions.

Functions as Arguments

Apply twice
let applyTwice = fun f -> fun x -> f (f x)

let double = fun x -> x * 2
applyTwice double 3
=> 12
Compose functions
let compose = fun f -> fun g -> fun x -> f (g x)

let double = fun x -> x * 2
let addOne = fun x -> x + 1

let doubleThenAddOne = compose addOne double
doubleThenAddOne 5
=> 11

Common Higher-Order Patterns

Map over a list
let rec map = fun f -> fun xs ->
  match xs with
  | [] -> []
  | h :: t -> f h :: map f t

let double = fun x -> x * 2
map double [1; 2; 3]
=> [2; 4; 6]
Filter a list
let rec filter = fun pred -> fun xs ->
  match xs with
  | [] -> []
  | h :: t ->
      if pred h then h :: filter pred t
      else filter pred t

let isEven = fun x -> x % 2 = 0
filter isEven [1; 2; 3; 4; 5; 6]
=> [2; 4; 6]
Fold (reduce) a list
let rec fold = fun f -> fun acc -> fun xs ->
  match xs with
  | [] -> acc
  | h :: t -> fold f (f acc h) t

// Sum using fold
let add = fun a -> fun b -> a + b
fold add 0 [1; 2; 3; 4; 5]
=> 15

Recursion

Recursive functions must be declared with let rec:

Factorial
let rec factorial = fun n ->
  if n <= 1 then 1
  else n * factorial (n - 1)

factorial 5
=> 120
Important
Without rec, the function name is not visible inside its own body. Always use let rec for recursive functions.

Why rec is Required

// This would NOT work (factorial not in scope):
let factorial = fun n ->
  if n <= 1 then 1
  else n * factorial (n - 1)  // Error: factorial not defined

// This works:
let rec factorial = fun n ->
  if n <= 1 then 1
  else n * factorial (n - 1)  // OK: rec makes it visible

Recursive List Functions

Reverse a list
let rec reverse = fun xs ->
  let rec helper = fun acc -> fun ys ->
    match ys with
    | [] -> acc
    | h :: t -> helper (h :: acc) t
  helper [] xs

reverse [1; 2; 3; 4]
=> [4; 3; 2; 1]
Append two lists
let rec append = fun xs -> fun ys ->
  match xs with
  | [] -> ys
  | h :: t -> h :: append t ys

append [1; 2] [3; 4]
=> [1; 2; 3; 4]
Tip
When writing recursive functions on lists, always handle the base case (empty list []) first, then the recursive case (h :: t).
